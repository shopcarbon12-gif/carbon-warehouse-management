Bottom toolbar — same buttons + geometry as the count screen

  • Bar 88 px white container with a soft top shadow, identical to count_inventory_screen.dart:2320's bottomBar.
  • Refresh (1/3) FilledButton · #2BA3A3 (same lighter teal count uses for SAVE TO FILE) · circular ⟳ icon · "REFRESH" label · flex: 1. Resets the session, drops back to fresh RFID-scan mode.
  • Search SKU (2/3) FilledButton · #1B7D7D Carbon teal · 🔍 icon · "SEARCH SKU" label · flex: 2. Disabled until _tags.isNotEmpty && !_isScanning — operator must scan at least one EPC, then toggle inventory off with a second trigger pull. While disabled the button greys to #BCC9C9.

Item container — count's _CountItemContainer with two trims

  • Removed price row, bin row. The operator doesn't need those during the encode pass; the SKU + name·color·size line is enough to confirm what's being rewritten.
  • Right slot bigger status pill: Space Grotesk · 13 px · w800 · ls 1.3, with 6 × 12 px padding. Stacked above a visible 1 px outlined red trash button (no swipe). For Phase 3 the spinner is 22 px (was 14).
  • No swipe the trash sits inside the container; the container does not slide. Tap-to-confirm via the same dialog count uses for delete.
  • State accent 4 px left-edge strip — teal mid-encode, green ✓, red ✗.

Search box + dropdown — bin-assign parity (with the font fix)

  • Search box teal-outlined 2 px rectangle, floating "Search item" label, large mono input (Roboto Mono · 22 px · w700) — identical geometry to Screenshot_20260528_080735.jpg.
  • Font fix dropdown rows: SKU stays teal (Roboto Mono · 18 px · w700). Description was 13 px grey → now 15 px black per request. Apply the same fix to the bin assign screen (fast_putaway_screen.dart's search dropdown rows).
  • 2D imager pill floats in the input's top-right corner, mirrors bin assign's existing trigger-relay indicator.

Power slider — thicker + live

  • Track 8 px tall (was 3 px). Easier to drop a finger on without missing.
  • Thumb 26 px circle with a 3 px white ring, 2 px drop shadow — large enough to grab with the operator's thumb while holding the device.
  • Value Space Grotesk · 14 px · w800; a small green LIVE pill confirms the new value pushes to the chip mid-scan (calls RfidVendorChannel.setAntennaPowerDbm through the 250 ms debounce, Zebra apply-mid-inventory with the inventoryActive race fix shipped in 1.2.80).

Phase 4 detail — bigger SAVE button + bigger TEST NEW TAG

  • SAVE button replaces the icon. Space Grotesk · 13 px · w800 · ls 1.2 · uppercase, 8×16 padding. Three states: SAVE dirty (amber background, prompts the operator to commit), SAVED persisted (green), and a disabled grey when the dropdown matches what's already in the items table.
  • TEST NEW TAG a 1.5 px teal-outlined tile with 12×14 padding · Space Grotesk · 14 px · w800 · ls 1.4 · uppercase — significantly larger than the previous icon-row variant. Opens encode_test_tag_screen with the new EPC pre-loaded.
  • Status dropdown font scaled to 14 px · w800 · black; consistent with the bigger SAVE button.
